개인정보 처리방침

시행 | 2026.07.25

이 문서는 wonzr가 제공하는 “골라 쓰는 ASMR 키보드”(이하 “서비스”)의 앱 및 키보드 기능을 사용할 때 개인정보가 어떻게 처리되는지 설명합니다. 서비스는 사용자가 입력하는 문장, 비밀번호, 메시지 내용 등 키보드 입력 내용을 수집하거나 저장하지 않습니다.

1. 수집하는 정보

  • 계정 정보: 계정 식별값, 로그인 제공자, 제공자가 전달한 경우의 이메일 주소
  • 계정 삭제 처리 정보: Apple 이벤트 고유값과 Apple 계정 식별값의 해시, 연결된 내부 계정 식별값, 이벤트 유형·시각과 처리 결과
  • 미니게임을 이용한 경우: 직접 정한 게임 별명과 시즌·대결 기록
  • 서비스 정보: 보유·적용한 키캡과 앱 설정
  • 쿠키 정보: 쿠키 잔액, 출석 보상, 사운드 잠금 해제에 따른 사용 내역
  • 문의 정보: 사용자가 고객 지원을 위해 직접 보낸 이메일과 내용

2. 수집하지 않는 정보

  • 키보드로 입력한 문장, 대화, 비밀번호, 카드번호
  • 연락처, 사진 라이브러리, 정확한 위치 정보
  • 다른 앱에서 작성하거나 주고받은 메시지 내용

3. 이용 목적

수집한 정보는 로그인과 계정 유지, 키캡 보유 및 적용 상태 저장, 쿠키 지급과 사용 처리, 출석 체크와 계정 삭제 처리에 사용됩니다. 문의 응대, 중복 삭제 방지, 부정 이용 방지와 서비스 품질 개선에도 필요한 범위에서 활용됩니다.

4. 외부 서비스

서비스는 로그인 인증과 데이터 저장을 위해 Apple, Google, Kakao, Supabase를 이용합니다.

5. 보관 및 삭제

개인정보는 서비스 제공에 필요한 기간 동안 보관됩니다. 사용자는 앱의 마이 > 회원 정보 > 회원 탈퇴에서 계정과 연결된 쿠키, 보유 사운드, 출석 기록과, 미니게임을 이용한 이력이 있는 경우 해당 기록을 직접 영구 삭제할 수 있습니다. 삭제한 계정과 데이터는 복구할 수 없으며, 법령상 보관 의무가 있는 정보는 해당 기간 동안 별도로 보관할 수 있습니다. Apple이 서명하여 전달한 계정 삭제 처리 기록은 원문 이벤트 고유값과 Apple 계정 식별값을 저장하지 않고 각각 해시 처리하며, 중복 처리 방지와 보안 확인을 위해 연결된 내부 계정 식별값·처리 결과와 함께 180일간 보관한 뒤 자동 삭제합니다.

6. 국외 처리

Apple, Google, Kakao, Supabase 등 외부 서비스 제공자의 서버가 해외에 있는 경우 일부 정보가 국외에서 처리될 수 있습니다. wonzr는 서비스 운영에 필요한 범위에서만 해당 서비스를 이용합니다.

7. 보안

wonzr는 접근 권한 제한, 인증 기반 데이터 접근과 암호화 통신 등 개인정보 보호를 위한 조치를 적용합니다. 다만 인터넷 환경의 특성상 모든 위험을 완전히 차단할 수는 없습니다.
